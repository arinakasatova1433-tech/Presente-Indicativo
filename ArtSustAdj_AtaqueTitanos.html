1.1 Соедини антонимы

Нажмите на слово, затем на его противоположность. Снизу будет формироваться список выученных пар с переводом.

Найдено пар: 0 / 12

  • Пока ничего не найдено...

1.2 Проверь перевод

Напишите испанское прилагательное по его русскому переводу.

Правильно: 0 / 24
✨ ¡Tatakae! Все пары и переводы освоены! ✨

2. Составь словосочетание

Образуйте словосочетание в единственном числе, а затем во множественном.

Правильно: 0 / 18
✨ ¡Eres un soldado de élite! ✨

3. Перевод и Множественное число

Переведите фразу на испанский (ед. число), затем поставьте её во множественное число.

Правильно: 0 / 18
✨ ¡El muro ha caído! ¡Felicidades! ✨

4. Describe la foto

Посмотрите на фото и опишите каждую из трёх частей картинки, используя словосочетания (прилагательное + существительное).
